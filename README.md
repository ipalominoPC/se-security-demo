# SMB Security Posture Assessment (Demo 1)

A static, no-login demo of a security posture assessment for a fictional small business.

- **Company:** Meridian Logistics Group (fictional, 120 people, ~150 endpoints)
- **Data:** fictional only
- **Stack:** static HTML/CSS/JS, Tailwind via CDN, no build step, no backend

## Structure

- `index.html` - landing view and app shell
- `data/` - question set and remediation content
- `js/scoring.js` - scoring engine
- `js/report.js` - report view and download
- `js/app.js` - entry point

## Status

Scaffold only. Logic and content are added in later steps.
